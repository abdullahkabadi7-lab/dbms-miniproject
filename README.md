# SMARTMART — Next-Gen Inventory & Order Management System

A high-performance e-commerce and inventory management application built with **React 18**, **TypeScript**, and **Tailwind CSS**. Designed for seamless shopping experiences with interactive cinematic entrances, real-time inventory management, and an admin operations console.

---

## 🌟 Key Features

### 🎬 1. Cinematic Scroll-Driven Entrance
- Seamless scroll-based scrubbing through optimized WebP frame sequences.
- Hardware-accelerated 60 FPS 2D canvas rendering with smooth lerp easing.
- Instant cut from the opening entrance visual into dynamic video progression with zero seek latency.

### 🔍 2. Interactive Supermarket Shelf Spotlight
- Fullscreen supermarket display featuring interactive cursor-following circular reveal.
- Smooth cursor tracking with soft feathered circular masking revealing the underlying empty shelf state.
- Pure CSS radial-gradient masking with lerp easing and zero pointer obstruction.

### 🛒 3. Real-Time Storefront & Catalog
- Curated organic reserve provisions and artisanal departments.
- Search by product title, brand, or SKU with live stock filter indicators.
- Instant reactive cart management and multi-item checkout flow.

### 🛡️ 4. DBMS Operations & Admin Console
- Live inventory ledger tracking on-hand, allocated, and available stock.
- Order management portal with transaction trails and deterministic stock decrements.
- Role switching between Customer and Administrator modes.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation
```bash
# Clone the repository
git clone https://github.com/abdullahkabadi7-lab/dbms-miniproject.git

# Navigate to project directory
cd dbms-miniproject

# Install dependencies
npm install
```

### Development
```bash
# Start local development server with Vite HMR
npm run dev
```
Open `http://localhost:5173` in your browser.

### Production Build
```bash
# Typecheck and build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
